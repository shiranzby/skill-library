# 验收和证据

Apple HIG 把设计建议、系统能力和实际设备环境分开。验收报告也要分层，不以截图、源码匹配或历史测试数量代替用户实际操作。

## 验收矩阵

| 层 | 要验证什么 | 证据例子 | 不能推出什么 |
| --- | --- | --- | --- |
| 静态/编译 | API availability、并发隔离、资源、可访问标签、警告 | 目标 SDK 的构建日志、lint、单元测试 | 不证明触摸、焦点、动画或硬件行为。 |
| 状态/单元 | 默认值、迁移、保存失败、取消、重试、Undo/Redo、迟到结果 | 隔离 repository、可重复测试、日志 | 不证明真实系统权限或窗口生命周期。 |
| UI 交互 | 点击/轻触、键盘、指针、VoiceOver、动态字体、深浅色、旋转/窗口缩放、拖放 | 真机/模拟器录屏、操作步骤、截图和几何数据 | 截图不能证明 hit target、焦点顺序或手势成功。 |
| 系统整合 | 权限、菜单、通知、分享、播放器、Widget/Live Activity、文件、外设 | 目标 OS + entitlement + 设备日志 | 模拟器结果不能代表传感器、显示、支付、蓝牙或相机。 |
| 视觉/内容 | 层级、可读性、对比度、本地化、空态、错误态、占位、长文本 | 浅/深色和最大字号截图，VoiceOver 读序 | 一张默认数据截图不能代表所有状态。 |
| 硬件/部署 | 真实设备、不同 DPI/窗口、Always On、远控、断网、恢复 | 设备型号、OS/SDK、权限、前后状态和复现脚本 | 文档建议不等于当前设备具备能力。 |

## 最小反例集

每个重要流程至少跑一次：

1. 首次启动、已有数据、空数据和升级迁移。
2. 快速重复输入、切换 query/页面、退出视图或取消任务时的迟到异步结果。
3. 保存成功、写入失败、权限拒绝、网络断开、恢复/重试和关闭应用后再打开。
4. 大字体、提高对比度、VoiceOver、键盘全导航、指针 hover、触摸和 RTL/长本地化字符串。
5. 破坏性操作的确认、取消、Undo、Redo；Popover/sheet 外部关闭和多层展示。
6. 最低支持系统、每个目标平台的窗口尺寸和方向；需要设备/entitlement 的能力单列为未验证。

## 运行记录格式

```text
目标：Settings 保存失败后保留输入并可重试
环境：iPadOS 18.x / iPad 型号 / SDK / 权限
步骤：输入值 → 断网 → 保存 → 查看错误 → 恢复网络 → 重试
预期：错误靠近字段；输入不丢；重试只提交最新 revision
实际：……
证据：测试日志、屏幕录制、保存文件 hash
结论：通过 / 失败 / 部分验证；未覆盖边界：……
```

## 当前 Windows 边界

本 skill 的资料阅读和原创总结在 Windows 完成。该环境没有 `xcodebuild`、Apple Simulator 或 Apple 真机时：

- 可以做 Markdown/代码结构审查、引用核对、跨平台边界审查和与真实 repository 隔离的状态测试。
- 不能声称 SwiftUI 编译、VoiceOver、Dynamic Type、visionOS gaze、watchOS Crown、Apple Pay、ARKit、WidgetKit、Live Activity 或真实 HIG 视觉验收通过。
- 如果项目是 Rust/Win32/WinUI/web，报告当前平台实测，并明确哪些规则只是借鉴；不要把 Windows 屏幕截图当作 Apple 平台证据。

## 完成标准

只有当目标平台的构建、关键反例、真实交互和所需系统能力都有对应证据，才可说“已验证”。缺少设备、权限或 SDK 时，用“文档/静态/替代测试通过，真实平台未验证”准确描述。
