# 组件与布局

## 1. 视觉基础

以下为新产品起点，不是所有项目的固定像素模板；已有合格令牌优先复用，适配时检查最终计算值，不只相信令牌名称。

| 系统 | 默认与约束 |
| --- | --- |
| 字体 | 中性系统无衬线，中文明确回退；正文 15–17px，辅助信息不承担主要操作；数字等宽，代码独立等宽字体 |
| 排印 | 紧凑页面标题约 22–28px、模块 17–20px；正文行高约 1.45–1.6；层级靠清晰字号／字重／位置，不用巨大 Hero |
| 间距 | 4／8／12／16／24／32 的少量语义令牌；模块间距大于内部间距，共享内边缘，避免多层重复 padding |
| 触区 | 常规交互目标至少 44×44 DIP；图形可小、命中不可相互覆盖；密度通过分组与空间职责实现 |
| 色彩 | 语义令牌：背景／表面／正文／次文／分隔／焦点／选中／成功／警告／危险；不在组件中散落主题色 |
| 明暗 | 浅色白与浅灰分层；深色中性灰黑，表面按灰阶分层；不机械反相，不给正文叠透明残影，不反转原图／纸张 |
| 对比 | 普通文字至少 4.5:1；关键控件与焦点清楚可辨；状态不只靠颜色，弱装饰线不能承担唯一边界语义 |
| 边界 | 模块用共享网格和必要发丝线分组；线约 0.5–1 CSS px 并检查实际 DPR；不为每行、每模块都画完整外框 |
| 圆角／层级 | 小而统一的控件圆角；工作面偏直线；仅真正覆盖层使用克制阴影，文字浮层优先不透明，层级集中管理 |
| 图标／箭头 | 同一图标体系与线宽；装饰图标不进读屏。默认不使用 Chevron、v 或旋转箭头装饰；展开、更多、翻月、刷新可用短文字，保留语义与键盘功能，不改用户原文或第三方界面 |

## 2. 页面空间与滚动

- **布局预算**：可用正文 = 宿主宽度 − 导航 − 辅栏 − 间隙／边框。按真实组件容器决策，不按整窗宽度猜测；Grid／Flex 子项合理设置 `min-inline-size: 0` 与 `min-block-size: 0`。
- **共同锚线**：标题、正文起点、工具、数值、行末操作各有稳定轨道；相邻模块按需要共享标题／行动／笔记轨道，可用 subgrid 或等效布局，不靠逐元素补偏移。
- **并排关系**：按职责用 1:1、3:2 或主内容＋辅助轨道；同排同上沿／下沿，内部按内容起排。不要巨大 `min-height` 拉空卡，亦不让单个长清单撑爆整页。
- **响应式**：组件内在宽度／容器查询优先；先收低频工具、再按需覆盖辅栏或改单列。短控件单行，工具组可以换组；长业务原文完整换行，URL 等长串可断词；不缩字、横向挤出或省成几个字。
- **展开稳定性**：抽屉、详情和筛选展开属于布局状态，不应改变对象身份或制造短暂溢出。用明确的最小／最大列宽、`min-inline-size: 0`、`overflow: clip` 或受控滚动面稳定过渡；不要以瞬时隐藏滚动条掩盖真实溢出。
- **正文与摘要**：阅读面保合理行长；工作列表使用有效宽度。仅摘要允许有入口的截断；编辑值、错误关键原因和唯一身份不能无从查看全文。
- **滚动责任**：默认一个主要纵向滚动面；持续目录／长清单确需独立滚动时，明确边界与键盘入口。隐藏滚动条须仍可滚动且有溢出提示，不能用 `overflow: hidden` 吞内容；避免同区域双滚。
- **窄屏边界**：保语义和主动作，浮层不出视口；移动场景检查 `100dvh`、安全区、触屏无 hover。二维数据不能无损重排时，保受控局部滚动或独立视图，不让整页横向溢出。

| 页面型 | 工作结构 |
| --- | --- |
| 总览 | 当前行动／状态／下一步／近期变化；同一事实只在一处表达，辅助月历放侧轨；稀疏内容真实留白，不造统计卡填满 |
| 计划／项目／学习 | 同一对象的不同视图用二级导航；行动优先、上下文次之；避免项目、日历、待办各复制一份任务；学习模块按空间自适应，笔记不默认藏起 |
| 阅读／知识／订阅 | 来源目录＋内容目录＋正文按需分层；宽屏原位阅读，窄屏覆盖；保存筛选、选择和滚动，不加无效“关联资料”占位区 |
| 设置／扩展 | 通用列表：名称、状态、主开关、按需详情；按任务分组，不把个别站点或实现细节堆在常驻说明中 |

## 2.1 三种视图模式与窄屏工具带

三种模式必须改变信息结构，而不是只换色：

| 模式 | 首要问题 | 首选结构 | 不应出现 |
| --- | --- | --- | --- |
| 设计风 | 我现在应该知道什么、先做什么？ | 结论／异常／摘要／下一步 | 无主次的 KPI 墙、装饰性大图 |
| 数据风 | 哪些对象、范围或账号需要比较？ | 汇总／筛选／稳定列轨道／趋势 | 把高数量对象塞进等宽大卡 |
| 卡片风 | 我能否快速扫过中等数量对象？ | 对象卡／状态／关键值／主动作 | 每张卡一行且留下大块空白 |

同一页面可只提供适用的模式；若提供多个模式，切换应保留对象、筛选、滚动和草稿。宽屏可用分段控件；约 639px 以下改为单个“当前模式”循环按钮，让搜索框和主动作保持可用。移动顶栏先保留安全区、44–48 DIP 触区、返回／菜单与上下文标题，再收纳低频搜索和筛选；检查 320、390、430 CSS 像素宽度及横屏：不得横向溢出，搜索框应有可输入的实际宽度，控件命中区不得重叠，`100dvh` 与安全区不能遮住主动作。模式切换、抽屉开合和侧栏拖拽都应在稳定的几何预算内完成，不能因为过渡帧短暂挤掉搜索框或主内容。

列表中的域名、Zone、URL、密钥名称等唯一身份默认完整显示；有空间就换行，不以省略号遮挡关键区分信息。若确需摘要截断，必须有稳定的全文查看入口和可访问名称。移动端卡片可以单列，但不应把整页变成无法定位的超长卡墙；高数量对象优先紧凑分组列表或表格。对象达到“需要比较、排序或批量操作”的数量阈值时，应退化为表格／分组列表；不要把大量账号、域名、凭据或资源强行摊成等高卡片。

## 3. 控件设计矩阵

所有交互具备正常／焦点／进行中／成功／失败／不可用状态中实际需要的部分；语义标签优先，禁用说明原因。动作用 button，导航用有真实 href 的链接。

| 组件 | 视觉与排版 | 必须可用的行为 |
| --- | --- | --- |
| 页面标题／工具带 | 唯一稳定主标题，二级视图不反复改身份；高频共带，次级弱化 | 动作跟随当前范围；主标题、窗口标签和对象身份不混淆 |
| 按钮／链接 | Filled／弱底／Plain；每工作面至多一个 Filled；短文案不拆行 | Enter／Space 按语义触发；防重复提交；链接鼠标与键盘可开；图标按钮有名称及可见提示 |
| 输入／搜索 | 持久标签，placeholder 不代替标签；错误紧邻字段，宽度留给真实内容 | 中文输入法组合不误提交；校验保输入；清除、取消、空结果可恢复；异步搜索防旧结果覆盖 |
| 表单 | 同组标签／输入／错误对齐；宽主辅、窄同 DOM 单列；保存带不遮正文 | 明确保存或自动保存策略；取消不提交；失败原稿原位重试；离开未保存表单有合理保护 |
| 选择／分段／菜单 | 少量互斥选项可分段，长集合可搜索选择；避免把所有选项做胶囊 | 选项值稳定；键盘选择、Esc 关闭、归焦；优先成熟可访问控件，不为删三角重写坏掉的 select |
| 复选／开关／进度 | 复选表示集合或完成；开关表示即时设置；进度含数值与单位 | 整行命中不和内部动作冲突；失败回滚并说明；进度来自真实结果，不伪报 100% |
| 列表／表格 | 主文、元信息、数字、操作各有列；表头同行对齐，细线按组 | 排序／筛选／分页真实改变结果并保状态；行内按钮不误开详情；大集合按需分页或虚拟化 |
| 空态／错误／通知 | 简短事实＋下一步，不用巨大插画；原位错误优先，Toast 只补充 | 区分未连接／加载／真空／受限／失败；关键错误持续可见；status／alert 合理宣告，不只瞬逝 Toast |
| Tooltip／帮助 | 短提示邻近触发项，不遮主操作；必要信息留在正文 | 焦点与悬停均可触发，触屏有入口；不靠原生 title 或 hover 承载唯一说明 |
| 弹窗／抽屉／Popover | 内容决定宽度、有限高度；遮罩与层级明确，少嵌套 | 模态才陷阱焦点；Esc、关闭后归焦；点击外部不意外丢稿；键盘和触屏均可达 |
| 侧栏／树／折叠 | 分组层级与缩进有节奏，选中态安静；设置等低频入口稳定 | 自定义名称／显隐／顺序保存；长按拖动不误导航；拖组、组内排序有边界；Esc 取消零写，提供键盘移动路径 |
| 工作标签／二级导航 | 页面类别与对象身份分离；标签不过度拉宽，长名有完整入口 | 不同对象／App 独立标签；切换保草稿和位置；关闭后焦点合理；页面局部筛选不覆盖其它标签 |
| 分栏拖拽 | 中性发丝线＋约 8 DIP 鼠标命中带；触屏需更易命中替代；无粗带、把手装饰 | 拖动、键盘调宽、复位、保存比例；最小正文预算；取消恢复；跨原生网页不丢拖拽，窄窗不改用户偏好 |
| 月历／日程／日期选择 | 完整七列日期和清楚选中态；多功能页作为辅助区，不占半页 | 工作日历／安排默认展开；前后月、今天、选日与编辑有效；日期触区预算含边框与 padding；日期选择弹层按需开 |
| 四象限／看板 | 象限真 2×2、空区占位、同排边界协调；看板各列有职责 | 原对象跨视图一致；长列表有界滚动；移动／归类可取消、失败不丢任务；不把象限降级成四个纵向分类 |
| 收藏／稍后看／订阅 | 列表或内容卡展示真实标题、来源、时间、备注；不重复堆工具条 | URL 导入、编辑、保存、阅读状态、收藏可恢复；同网址可发现多个订阅候选；失败允许手填，不伪造抓取 |
| 编辑器／笔记／大纲 | 正文优先，大纲按需；长文不缩小字号，选择与行高稳定 | 原文精确保留；保存／撤销／搜索／跳转／恢复有效；本地链接和图片按授权源路径解析，不擅自复制改写原件 |
| 文件／文档预览 | 文件事实、预览、下载分工；纸张／图片不随深色粗暴反相 | 真实样本验图片、分页、链接、缩放；DOCX／PDF 能力分别声明；部分支持明确降级，不把扩展名识别当完整支持 |
| 内嵌 App／网页阅读 | 内容占主区，紧凑地址与历史工具，不重复展示一整排 App 卡 | 自定义名称／URL／图标；正常链接尽量留当前容器，前进／后退／刷新有效；尊重认证弹窗和跨域限制，失败提供外开，不宣称全控 |
| 图表／活动记录 | 结论、单位、时间范围优先；细线、少色、对齐数值 | 真数据、加载／空／错误明确；趋势和汇总可追溯，不用装饰图表占工作面 |
| 命令面板 | 搜索＋分组结果＋快捷键提示，不复刻一整套菜单 | Ctrl／Cmd+K、方向选择、Enter、Esc、归焦；执行当前对象命令，避免劫持编辑器或第三方网页快捷键 |

## 4. 动效与视觉验收

- 交互反馈立即开始；高频键盘操作不等动画。常见局部反馈约 100–180ms、面板约 180–280ms，均可中断；状态信息立即更新。
- 只为因果、状态和空间关系服务；优先颜色／透明度／小幅 transform，不给每卡入场、逐项延迟、持续漂浮或长列表做高度动画。
- `prefers-reduced-motion` 保留终态与功能；不以隐藏焦点、滚动提示和失败状态追求“干净”。
- 最终检查当前产物：典型桌面、窄窗、超宽，以及适用的移动尺寸；浅／深、空／长／多数据、错误／展开。逐张查看真实截图，分别检查网格秩序与实际可读性，不只数溢出为零。
