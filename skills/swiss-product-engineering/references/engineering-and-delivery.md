# 工程、测试与交付

## 1. 架构与状态归属

采用项目现有架构；以下是逻辑边界，不要求机械建立四层目录、通用平台或一套新的框架。

| 边界 | 负责 | 避免 |
| --- | --- | --- |
| 视图／交互 | 呈现、表单草稿、焦点、工作标签、筛选、滚动 | 把布局状态写成业务事实；组件直接读写数据库、系统文件或密钥 |
| 领域命令 | 校验、业务规则、稳定 ID、关联、状态转换 | 各页面独自复制任务／进度；用路由类别代替对象身份 |
| 存储／服务 | 提交、查询、事务／原子替换、版本迁移、备份恢复 | 静默部分写入、失败返回空成功、恢复时覆盖新资料 |
| 外部适配 | 网络、文件授权、文档解析、网页容器、来源映射 | 把供应商字段和错误直接散入 UI；来源故障拖死整个产品 |

- **单一事实源**：首页、项目、日程、学习读取同一对象；视图转换不造新 ID。偏好、草稿、业务、凭据分别存储；自动响应式不改用户保存宽度／顺序。
- **契约优先**：边界定义输入／输出、可空字段、稳定错误码、版本兼容；字段和对象权限在可信层校验。Web 用相应 API，桌面用窄 IPC，不把任意命令执行器暴露给页面。
- **异步一致性**：使用请求身份／版本或取消令牌防迟到覆盖；切页、改选、编辑和删除后，旧响应不得复活对象。乐观更新只用于可回滚操作，失败保精确草稿。
- **提交语义**：取消不写业务；提交成功才清稿；重复提交按业务需要去重或幂等。自动保存明确等待／保存中／失败，重启后能恢复已承诺保存的状态。

## 2. 数据、接口与外部能力

| 场景 | 必须守住的结果 |
| --- | --- |
| 写盘／数据库 | 使用原子替换或事务；必要时版本／冲突检测；禁止写坏旧版本后再报错；路径、数据量与结构有合理边界 |
| 迁移／导入／恢复 | schema 版本、原 ID／原文／排序、冲突策略、备份与可回退；真实样本检验，不把覆盖式导入默认当合并 |
| 授权文件 | 规范化真实路径与允许根，处理符号链接和目录替换；主进程／服务验证权限；取消选择不丢旧授权；不擅自复制或改写用户原件 |
| 网络／同步 | 有界并发、总超时、取消和有限重试；失败保缓存并标记时间／来源／过期状态；可选元数据失败不能丢掉有效正文 |
| 刷新去重 | 合并请求也要覆盖范围：单来源进行时收到全量刷新不能只返回旧 Promise；变更后的接续工作明确，计数不夸大成功 |
| 本地解析／RSS | 内置解析仍依赖上游可访问；网页可有多个订阅候选；使用真实已安装解析能力，不只换名称；认证、验证码、限流如实反馈 |
| 凭据／登录 | 只按授权迁移需要的登录数据；Cookie 副本不等于全部凭据或离线沙箱；不进日志／截图／业务备份，不把活跃可写 Profile 共用于多实例 |
| 缓存／锁库 | 已有可用本地副本优先就绪，来源后台刷新；来源锁定只影响更新，不清缓存、不要求退出另一程序作为日常使用条件；首次无副本明确说明 |
| 网页／扩展 | 远端内容无 Node／任意文件能力；按容器真实能力控制导航与新窗口；逐项声明扩展兼容，不承诺所有浏览器插件都能运行 |
| 本地服务 | 按需启动、复用、健康反馈、失败可重试；跟踪归属 PID／端口并收束自己启动的进程；禁止按进程名批量结束 |
| 性能／资源 | 预算随场景确定；长列表按需渲染、后台任务有界；避免多套常驻浏览器、无界轮询、无上限附件与缓存；疑似回归先测量再优化 |

错误区分：**未连接／无数据／输入错误／权限不足／受限／超时／写入失败／部分完成**。保留可操作原因与重试；不泄漏敏感正文，不将错误转换成成功空集。一次实网成功不等于长期稳定，Fixture 不等于真人账号验收。

## 3. 验证分层

先复现用户动作，建立能抓住旧问题的定向反例，再修复。断言行为与不变量，不只匹配文案、类名或源码正则；静态合同仅作补充。完整回归用于阶段合流或共享行为变动；同构建、同环境的既有证据可按影响范围复用，不反复无目标全扫。

| 层 | 证明什么 | 典型检查 |
| --- | --- | --- |
| 静态／构建 | 代码可解析、类型与资源引用成立 | 最终保存版本的类型、lint、构建；声明可用的入口确实能启动 |
| 单元／领域 | 规则与状态转换正确 | 原 ID、排序、边界值、迁移、取消、迟到与重复请求 |
| 契约／集成 | 真实模块边界可协作 | IPC／API 校验、写盘失败、超时／限流、解析样本与缓存保持 |
| 真实交互 | 控件驱动实际行为 | UI 新建／修改／保存／取消／失败重试，鼠标语义与键盘路径，标签不串草稿 |
| 持久化／重启 | 不依赖当前内存假象 | 新进程重新打开，恢复对象／偏好／已保存状态；重解析定位器，不复用旧进程 DOM |
| 几何／可访问 | 控件空间与可达性 | 实际 computed 字号、命中、对齐、溢出、浮层、滚动、焦点、长中文与 URL |
| 当前像素目视 | 真实风格与可读性 | 目标客户端／当前构建，多主题与内容密度；检查共同网格、噪音、层级，首屏和滚后区分 |
| 外部实况 | 真实来源／文件／账号能力 | 按授权实测，记录来源与时间；Fixture 与实网分开，单次与稳定分开，未验不冒称完成 |

最小闭环集合：**正常保存 → 取消零写 → 失败保稿与旧数据 → 恢复后重试 → 切换保身份 → 新进程恢复**。按实际风险选择相关分支；不为纯排版修复运行无关云端操作。

视觉证据须对应最终代码与目标产物，记录版本、尺寸、主题和场景，逐张打开检查；隐藏捕获遇旧主题／残帧先修证据路径，不抢焦点补图。修改后重验受影响证据，保留原失败与补验，不能只报最后绿色。

## 4. 日用与测试隔离

| 资源 | 日用实例 | 开发／测试／候选 |
| --- | --- | --- |
| 代码／入口 | 固定版本产物，启动不编译源码 | 独立产物、可辨识版本与一键入口，不原位热改日用 |
| 数据／Profile | 用户真实资料与登录 | 默认合成样本、独立目录；必要时授权只读或脱敏副本，不回写 |
| 服务／生命周期 | 用户控制开启、关闭、升级 | 独立端口、缓存、PID 与服务配置；只停止自有测试进程 |
| 文件／账号 | 原件与真实远端 | 隔离文件做失败注入；登录副本仍是同一远端，默认只读，不注销、发消息或改云文档 |

- 后台测试不使用前台键鼠、不显示／激活／聚焦窗口、不关闭用户应用。工具不能满足时记录未验边界，不悄悄降级为前台操作。
- 隔离需要实际验证构建、测试、重启不改变日用文件／状态／进程／服务；仅有两个 BAT 或不同业务目录不算充分隔离。
- 新候选独立验证固定产物，交付明确目录和入口。默认只保留当前与上一可回退候选；旧版经授权可恢复归档，运行中的版本延后，不动日用数据、不默认删除。
- 更新由用户选择时机；升级前备份，代码回退不得抹去新增业务数据；不兼容迁移必须有匹配的数据恢复方案。

### 4.1 生产发布与静态演示边界

- GitHub Pages 演示应复用仓库的真实前端构建，仅替换 API 为明确标注的静态适配器和合成数据；禁止另造一套“看起来像”的页面。
- Pages、候选、生产分别记录提交、构建、部署、健康检查和资源指纹；演示通过不能代替生产上线成功，生产成功也不能证明演示无个人数据泄漏。
- Cloudflare／Docker 发布凭据只从本机登录态、环境变量或托管 Secret 读取，不写仓库、截图、日志或 Skill。允许无凭据完成本地构建和静态验证；缺少部署凭据时仅阻断外部推送／部署，并准确报告阻塞，不从业务页面或 Cookie 反向提取部署权限。
- 应用鉴权与入口防护分层记录：用户名／密码、可选 TOTP(MFA)、Bearer Session 属于应用鉴权；反向代理、VPN、Cloudflare Access 属于网络层控制。`ADMIN_TOKEN` 仅作为高权限应急旁路，默认不配置，不能被描述为细粒度权限系统。
- 鉴权验收至少区分 signed-out、登录中、authenticated、过期需重新登录、forbidden、受限／降级；401 回登录或刷新，403 说明权限／Scope，429 和超时保留草稿并提供重试，不把失败变成空成功。Token 不进入 URL、hash、日志、截图或备份。
- 发布证据至少包含 commit SHA、构建命令与结果、artifact hash／资源指纹、工作流 run 或部署版本、外部 URL、健康检查时间与响应、一个真实 smoke flow；缺 URL 或健康结果不得宣称生产完成。

## 5. 开发节奏与记录

- 优先级：启动与数据风险 → 主动作闭环 → 跨模块一致性 → 密度与视觉 → 可延期增强；不以全产品尚未完善阻止可用阶段交付。
- 原则：问题驱动，最小有效改动；重大结构问题允许成片重做，但保数据、列收益、分阶段验证，不做无目标美化。
- 停止条件：验收达到就交付；需要新权限或关键外部条件时报告准确边界。同题反复失败时停下重审根因与方案，避免持续小修堆补丁。
- 持续文档只维护一个当前状态入口：需求／已交付／未完成／下一步／证据。长期原则进入已有项目规范；历史结论标明版本，不复制测试数量作新事实。
- 交付区分“源码已改”“当前构建已验”“固定候选可用”“日用已升级”；未做的阶段不得互相替代。
